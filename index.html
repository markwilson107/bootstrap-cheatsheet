Responsive breakpoints

Bootstrap is mobile-first. Classes without an infix apply at every width; classes such as col-md-6 start at the named breakpoint and continue at larger sizes.

Breakpoint Class infix Dimensions
Extra smallNone<576px
Smallsm≥576px
Mediummd≥768px
Largelg≥992px
Extra largexl≥1200px
Extra extra largexxl≥1400px

Example: col-12 col-md-6 col-xl-4 is full width on phones, half width from medium screens, and one-third width from extra-large screens.

Image basics

Keep images responsive and control their height without changing their natural proportions.

Image docs ↗
Responsive image
Show code 
<img
  src="image.jpg"
  class="img-fluid"
  alt="Describe the image"
>
Fixed height without stretching — crop to fill
Show code 
<img
  src="image.jpg"
  class="w-100 object-fit-cover"
  style="height: 240px;"
  alt="Describe the image"
>

object-fit-cover preserves the image proportions, fills the entire fixed-height area, and crops any overflow.

Responsive 16:9 image
Show code 
<div class="ratio ratio-16x9">
  <img
    src="image.jpg"
    class="w-100 h-100 object-fit-cover"
    alt="Describe the image"
  >
</div>

A ratio wrapper changes height with the available width, which is often more flexible than a fixed pixel height.

Changing theme colors

Override Bootstrap variables for page-wide colors, or component variables to change one button without affecting the others.

Color docs ↗
Preview
Theme-colored text
Show code 
<!-- Place overrides after the Bootstrap stylesheet. -->
<style>
  /* Change Bootstrap's default theme values across the page. */
  :root {
    --bs-primary: #6f42c1;
    --bs-primary-rgb: 111, 66, 193;
    --bs-link-color: #6f42c1;
    --bs-link-hover-color: #59359a;
  }

  /* Change only buttons that use the custom btn-brand class. */
  .btn-brand {
    --bs-btn-bg: #6f42c1;
    --bs-btn-border-color: #6f42c1;
    --bs-btn-color: #fff;
    --bs-btn-hover-bg: #59359a;
    --bs-btn-hover-border-color: #59359a;
    --bs-btn-hover-color: #fff;
  }
</style>

<button type="button" class="btn btn-brand">Brand button</button>

<!-- Or override one button directly. -->
<button type="button" class="btn btn-primary"
  style="--bs-btn-bg:#b02a37;--bs-btn-border-color:#b02a37;">
  One-off button
</button>
